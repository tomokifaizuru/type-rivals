# Type Rivals

Type Rivals is a mobile-first online typing battle. Words fall from the sky and you type them before they land. Clearing words and combos sends red attack words to your rivals, and the last one standing wins.

**Play:** https://tomokifaizuru.github.io/type-rivals/

- **Online rooms:** 2–8 players. Create a room for a 5-character code, or join one with a code.
- **Same words:** every player gets the same seeded word stream.
- **Attacks:** combos and long words send red attack words to rivals.
- **Practice:** solo mode with a local high score.
- **Networking:** peer-to-peer using PeerJS/WebRTC. The host's browser runs the room; no server is needed.
- **Version:** v1.04
